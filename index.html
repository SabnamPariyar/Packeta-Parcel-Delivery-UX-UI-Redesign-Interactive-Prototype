UX design / portfolio case study

Designed for the
moment that matters.

An independent exploration of how a parcel delivery product can become clearer, more reassuring and more inclusive. This is a concept project, not a claim of commissioned work or a measured improvement to Packeta's existing app.

Project framing

The opportunity

Less uncertainty between checkout and collection.

Parcel journeys involve waiting, status changes, handoffs and time-sensitive collection. The concept prioritizes the questions people naturally ask: Where is it? When can I collect it? What do I do next?

The design response

A clear hierarchy with actions in context.

Progress stays visible, pickup choices are easy to compare, and returns are framed as short, manageable tasks.

Method & deliverables

Concept-stage framework
01

Discover

Audit the current product and map journeys. Proposed next step: interview 5–7 parcel users.

02

Define

Prioritize tracking clarity, pickup selection and return confidence.

03

Design

Build flow maps, responsive screens and a reusable visual system.

04

Validate

Proposed next step: test task completion, comprehension and accessibility with real users.

Three core journeys

Track

Status → next step

A step-by-step delivery timeline, contextual instructions and one clear action.

Choose

Location → confidence

Compare nearby collection options before confirming a preference.

Return

Problem → resolution

A calm guided return experience with concise instructions.

What would be tested next?

Can a first-time user find their parcel's next action within 10 seconds—without guessing?

Suggested study: 5–7 moderated usability sessions, keyboard and screen-reader review, and comparison of task completion time and error rate. No user testing results are claimed yet.
