# Packeta — Visual Design System

The system supports a clear, approachable delivery interface across desktop and mobile.

## Color palette

| Token | Hex | Usage |
| --- | --- | --- |
| Action Red | `#E83243` | Main calls to action, progress and attention |
| Deep Red | `#C91F32` | Hover and active emphasis |
| Ink | `#17191C` | Headings, primary content |
| Canvas | `#F8F8F7` | Application background |
| White | `#FFFFFF` | Elevated cards and controls |
| Muted | `#767B83` | Supporting text |
| Border | `#E6E6E8` | Dividers and input boundaries |
| Success | `#188567` | Completed / available states |

## Typography

- **Manrope:** display typography, headings, prominent numbers and brand-level messages.
- **DM Sans:** labels, interface text, explanatory copy and controls.
- Suggested scale: 64px display, 42px section heading, 24px card heading, 16px body, 14px label.

## Layout and spacing

An 8px spacing rhythm (8 / 16 / 24 / 32 / 40) with a responsive 12-column desktop layout. Control radius 12px, card radius 20px, hero radius 27px.

## Component inventory

- Primary, secondary and disabled action buttons
- Text inputs and toggle state
- Status badges for *In transit*, *Ready* and *Delivered*
- Shipment cards and progress timeline
- Pickup-point selection cards and illustrative map pins
- Confirmation feedback toast
- Desktop tabs and mobile tab bar

## Interaction principles

1. **One main action** per task-focused card.
2. **Visible progress** with a plain-language next step.
3. **Human language** over internal logistics terminology.
4. **Accessible interaction** with keyboard focus states, clear labels and touch-friendly targets.

## Visual inspiration

The [moodboard inside the live prototype](https://sabnam-packeta-concept-2026.sandeep-pariyar.chatgpt.site) links architectural clarity, packaging materiality and everyday mobility to the UI choices. External photographs are credited as visual references.
